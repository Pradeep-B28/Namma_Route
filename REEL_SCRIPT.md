## Production Notes

1. **Recording Tips:**
   - Use Google Chrome or Microsoft Edge at 100% display scale.
   - For vertical reels, set browser window to 390 by 844 or use developer tools device emulation.
   - For horizontal video, set browser window to 1440 by 900 or 1920 by 1080.
   - Navigate to `?demo=1` to record uninterrupted looping footage.

2. **Style Compliance:**
   - No emojis in any on-screen text or captions.
   - No em dashes or en dashes in voiceover or overlays.
   - All branding matches Wrench Wise design guidelines.
