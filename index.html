1. What a graph is

A graph is a network of points called vertices, connected by lines called edges.

In Namma Route, each city is a vertex and roads or railway lines are edges.

Each edge has a travel time in minutes based on real distance and average speed.

2. Road, train or both

Cities are split into a road node and a rail node.

In Any mode, switching between road and train in the same city takes 30 minutes.

This penalty accounts for transferring at transit hubs like Mettupalayam or Madurai.

3. Dijkstra

Dijkstra was invented by Edsger Dijkstra in 1956.

It finds the fastest route by exploring outward in all directions from the start city.

It always checks the nearest reachable node first using a min-heap priority queue.

It has no sense of direction, so it searches behind as well as ahead.

4. A* and its estimate

A* improves on Dijkstra by using a directional straight-line estimate.

The estimate uses the haversine formula multiplied by a safe speed constant k.

Because the estimate never overestimates remaining time, A* always finds the true fastest route while checking far fewer cities.

5. BFS (Fewest Stops)

BFS explores the network level by level, like ripples spreading across water.

It finds the route with the fewest stops between cities, ignoring travel time.

6. Min-heap priority queue

Both Dijkstra and A* pick the lowest cost node in O(log N) time with a binary min-heap.

Ties are broken alphabetically by node name for consistent and repeatable results.
